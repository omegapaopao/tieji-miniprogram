========== echarts-for-weixin 组件安装 ==========

请从 GitHub 下载 ec-canvas 组件并放置在此目录:

方法 1: git clone
  git clone https://github.com/ecomfe/echarts-for-weixin.git
  将 ec-canvas 目录下的 ec-canvas.js / ec-canvas.json / ec-canvas.wxml / ec-canvas.wxss 复制到这里

方法 2: 直接下载
  打开 https://github.com/ecomfe/echarts-for-weixin
  点击 Code → Download ZIP
  解压后，将 ec-canvas 目录下的 4 个文件复制到 lib/echarts/

放置后目录结构应为:
  miniprogram/lib/echarts/
    ├── ec-canvas.js
    ├── ec-canvas.json
    ├── ec-canvas.wxml
    └── ec-canvas.wxss

如果暂时不需要图表功能，统计页的折线图将不显示。
